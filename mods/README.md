# Mods e arquivos do jogo (NUNCA commitar)

Use a sua cópia legítima de Pizza Tower (Steam). Arquivos do jogo e do mod têm direitos autorais:
não suba data.win, bancos de áudio nem o mod pronto para o GitHub (o git também recusa arquivos acima de 100 MB).

## Destino no PS4 (convenção do projeto, ainda a ligar no runner)
- /data/pizza-tower/data.win e demais arquivos/pastas do jogo
- alternativa: /mnt/usb0/pizza-tower/

## Mod obrigatório: ícones de botões do PS4
- Nome/link do mod: PREENCHER
- Aplique o mod na SUA cópia do jogo e copie o resultado para o PS4 (USB ou FTP).
- Cruz deve aparecer onde o jogo mostra o botão face1, Círculo em face2, etc. (config/controller_map.ini).

## Menu Video Settings
- Fase 1 (runner): config/ps4_video.ini trava o vídeo; a opção deixa de ter efeito.
- Fase 2 (data.win): remover a entrada do menu exige editar o código do jogo com um script do UndertaleModTool.
  Escrevemos depois de listar os nomes reais do menu.
